# 🍞 Bread Crew Website

Official community website for **Bread Crew**, an international Clash of Clans clan family.

🌐 **Website:** https://breadcrew.github.io/site/  
💬 **Discord:** https://discord.com/invite/breadcrew  
▶️ **YouTube:** https://www.youtube.com/channel/UCLmD2WN4v5698R3k-Q07QJw

The website is intentionally simple: static HTML and CSS hosted through GitHub Pages. This makes it easy to maintain, update and improve as a community.

# 🛠️ Contributing on GitHub

If you are comfortable using GitHub, you can contribute directly to the website.

### 1. Choose what you want to improve

Find the relevant file:

- Homepage → `index.html`
- Tools → `tools.html`
- Meta strategies → `meta.html`
- Visual/layout changes → `styles.css`

### 2. Create a new branch

Please avoid making experimental changes directly on `main`.

Create a new branch for your update.

Examples:

`add-new-tool`

`update-meta-strategy`

`fix-broken-link`

`improve-tools-page`

### 3. Make your changes

Edit the file directly on GitHub or use your preferred code editor.

Try to keep the existing structure and visual style of the website.

### 4. Commit your changes

Use a short and clear commit message.

For example:

`Add ClashFox Attack Finder`

`Update current meta strategies`

`Fix Clash Ninja link`

### 5. Open a Pull Request

Create a Pull Request from your branch into `main`.

Briefly explain what you changed and why.

Once reviewed, the change can be merged and GitHub Pages will automatically update the live website.

# ✅ Keep Contributions Simple

The goal of the Bread Crew website is not to become a huge wiki.

We want it to remain:

**Useful. Current. Easy to browse.**

When adding something, ask:

> Would this genuinely help another Clash player?

If yes, it probably belongs here.

---

# 🛡️ Fair Play

Bread Crew does not promote cheats, attack bots, farming automation, gem generators, modified clients or tools designed to interfere with Clash of Clans gameplay.

Contributions involving these tools will not be accepted.
